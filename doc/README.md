## 这个库解决的是什么问题

`user-client` 里有 **3666 处颜色字面量、只有 925 处令牌引用**（约 4:1）。
颜色散落在页面里，所以「改一次主色」实际要做的是找出这 3666 处里哪些该改——
这就是当初「换掉 Element Plus 顺便把外观统一起来」做不动的根因，不是组件库本身不好换。

本库的应对不是「再写一套组件」，而是**建一层约束**：颜色只能来自令牌，
组件层不许写裸色值。有了这层，「换主题」才真的只是换一组变量值。
